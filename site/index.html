No plugin hunt. No extra installs. The important tools ship with the agent.

Web access

Search and fetch pages without API keys. Docs, GitHub, and current answers stay in the loop.

Long context

2–6 specialized workers — scout, implement, test, review — in parallel or chained.

How it works

Three steps. Then you're coding.

1

Install

One curl line. Requires Node 22+. CLI: eaon-code.

2

Setup

First launch lets you choose a provider and theme. Eaon Plan is listed alongside other providers. Re-run anytime with /setup.

3

Work

Type a task. Use swarm for big work, plan when you need a map, web when you need current facts.
